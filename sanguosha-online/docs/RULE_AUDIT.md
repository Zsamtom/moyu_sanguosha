# 原版规则差异核查

核查日期：2026-07-20

原版基准：`../sanguosha-master`（wzk1015/sanguosha）
发布规则版本：`original-66-v1`

## 核查结论

当前规则目录覆盖原版默认牌堆的 41 类、160 张实体牌，覆盖 66 名武将和 124 个唯一技能规则。全部武将均进入实时 `GameSession`，不再是仅有元数据的占位实现。

规则覆盖由以下自动门禁验证：

- `shared/test/deck.test.ts`：原版 160 张牌堆组成。
- `shared/test/full-general-catalog.test.ts`：66 名武将及包、势力、性别、体力和技能目录。
- `shared/test/skill-rule-text.test.ts`：124 个技能名称与中文规则文本完整且唯一。
- `shared/test/live-skill-coverage.test.ts`：124 个技能和 66 名武将均标记为实时接入。
- 各 `live-*.test.ts`、卡牌、装备、伤害、判定、濒死、死亡与持久化测试：实际结算路径。

自动测试可以证明目录覆盖和已列场景，不等于穷举所有武将、卡牌、断线时点的组合。发布前仍应进行多人浏览器验收和长局回归。

## 有意保留的差异

| 范围 | 原版 Java | 当前版本 | 原因 |
| --- | --- | --- | --- |
| 主公分配 | `GameManager.init()` 固定玩家 1 为主公 | 所有房间成员（含房主、机器人）一起随机身份 | 本次产品要求，避免房主长期固定为主公 |
| 运行方式 | 单机多人，共享本地进程输入 | 多房间、账号制、服务端权威、浏览器实时同步 | 联机产品架构要求 |
| 隐私与校验 | 本地进程直接持有全部状态 | 手牌、身份和私有选择按查看者投影，所有操作由服务端复验 | 防作弊与断线恢复要求 |
| 自定义身份数 | 命令行可手工配置身份数量 | 使用原版 2–10 人默认身份表 | 当前房间配置尚未开放自定义身份数量 |

## 原源码冲突的明确裁决

`shared/src/rule-config.ts` 的 `SOURCE_CONFLICT_DECISIONS` 保存 66 项机器可读裁决。它们不是遗漏，而是对原 Java 的代码、说明和同年代规则冲突作出的显式选择。主要包括：

- 三尖两刃刀有类定义但未加入 `CardsHeap`，因此不进入原版 160 张牌堆。
- 标准包采用许褚；荀彧归入火包，修正原 `PeoplePool.addStandard()` 的误放与漏将。
- 紫骍、集智、武神/武魂、狂暴等显示名称采用规则说明中的正确名称。
- 神将势力在开局选择魏、蜀、吴、群之一，不保留空势力。
- 对原实现中不完整或互相矛盾的复杂技能，采用同年代规则并将结算边界写入测试。

完整裁决及理由以 `SOURCE_CONFLICT_DECISIONS` 为准。
