# 三业庄园长线改造设计

状态：实施中
适用范围：农场、牧场、矿山、共享规则、服务端、Web 客户端
目标版本：三业庄园 v1

## 1. 改造目标

把当前“先农场、再牧场、最后矿山”的线性成长，改造成农、牧、矿同步运行的循环经营系统。

本次改造不扩张好友玩法，重点解决以下问题：

1. 低级短周期产物经验效率过高，重度玩家可以快速刷满等级。
2. 后期金币产出远高于永久消耗，升级完成后经济失去约束。
3. 三个板块主要是等级门槛和原料消耗关系，缺少可反复规划的生产网络。
4. 当前内容存在明确终点，满级、扩满槽位后只剩重复收取。
5. 市场 LLM 只影响农场价格叙事，尚未理解完整庄园。

目标体验：

- 第一天开放农、牧、矿三个基础板块。
- 第 7 天建立第一条跨板块加工链。
- 第 30 天完成基础庄园设施。
- 第 60 天进入高级育种、深层矿山和复合订单。
- 第 90 天完成首个赛季研究目标。
- 满级后仍可通过订单组合、收藏、研究和世界事件产生新决策。

## 2. 设计原则

### 2.1 三业平等

农场不是主玩法，牧场和矿山也不是附属资源点。每个板块必须：

- 拥有自己的短期决策；
- 独立提供基础收益；
- 向其他两个板块输出关键资源；
- 接受其他板块的效率增益；
- 在联合订单和长期建设中具有不可替代的作用。

### 2.2 软联动，不制造死锁

跨板块加工提供更高收益和长期进度，但基础循环不能因为缺少一种资源完全停止。

- 基础原料始终可以通过本板块恢复。
- 必需原料可以从 NPC 市场高价补购。
- 联合生产提高效率，不是登录和继续游戏的硬门票。
- 事件不能无预警摧毁长期成果。

### 2.3 决策延寿，不靠纯数值延迟

不采用简单扩大经验阈值、增加等待时间的方式延长寿命。长期性来自：

- 有限设施队列形成的机会成本；
- 市场、天气和订单组合变化；
- 品种、动物特质、矿层与遗物收藏；
- 城镇工程和研究带来的永久改变；
- 软赛季提供的新生产问题。

### 2.4 规则权威，LLM 只做导演

LLM 可以选择经过验证的候选事件并生成叙事，但不能：

- 任意生成金币、物品或倍率；
- 绕过等级和库存校验；
- 直接修改成熟时间和掉落概率；
- 决定操作是否合法；
- 保存无限长度的玩家输入或对话。

## 3. 三业资源循环

| 板块 | 核心产出 | 输入到其他板块 | 获得的反哺 |
|---|---|---|---|
| 农场 | 作物、棉花、药草 | 饲料、口粮、麻布、加工原料 | 有机肥、矿物肥、工具、灌溉设备 |
| 牧场 | 蛋奶、羊毛、兔绒、皮革、粪肥 | 食品、纺织、防护、肥料原料 | 饲料机、围栏、保温设备、矿物盐 |
| 矿山 | 煤、金属、石料、磷矿、盐 | 农具、机械、建筑材料、矿物肥 | 口粮、布袋、防护服、绳索 |

核心闭环：

```text
农场作物 → 饲料 → 牧场产品 → 肥料 → 农场增产
```

```text
矿石 → 工具与机械 → 农场/牧场效率提升
```

```text
农场棉花 + 牧场羊毛/兔绒 → 矿山防护 → 深层矿脉
```

## 4. 统一成长体系

### 4.1 庄园声望

庄园声望通过联合订单、首次配方、设施建设和世界事件获得。它负责解锁公共设施和长期章节，不直接替代三个板块的专精等级。

### 4.2 板块专精

- 农场专精：土壤、天气适应、轮作、育种。
- 牧场专精：饲料配方、健康、繁育、动物特质。
- 矿山专精：勘探、加固、冶炼、深层矿脉。

### 4.3 设施研究

长期资源消耗集中在设施解锁、升级和研究，而不是高额日常维护。

首批设施：

| 设施 | 主要输入 | 主要输出 |
|---|---|---|
| 磨坊 | 小麦、玉米 | 面粉、粗饲料 |
| 饲料厂 | 作物、矿物原料 | 高级饲料 |
| 肥料厂 | 作物残渣、牧场副产、矿物 | 复合肥 |
| 厨房 | 作物、蛋奶、燃料 | 食品与订单商品 |
| 纺织坊 | 棉花、羊毛、兔绒 | 布料、防护用品 |
| 冶炼炉 | 煤、矿石 | 金属锭 |
| 机械工坊 | 金属、布料、牧场材料 | 农具、牧场设备、矿山设备 |

### 4.4 图鉴与研究

- 变异作物和稳定品系；
- 动物特质和稀有毛色；
- 矿层、矿物和遗物；
- 配方首次完成；
- 季节研究和城镇工程。

图鉴提供永久但可控的横向增益，不能形成不可追赶的指数增长。

## 5. 统一订单

### 5.1 订单层级

| 类型 | 周期 | 用途 |
|---|---|---|
| 单板块订单 | 数十分钟到 1 天 | 教程和基础周转 |
| 双板块订单 | 1 到 3 天 | 建立产业链 |
| 三板块工程 | 3 到 14 天 | 庄园与城镇长期建设 |
| 赛季研究 | 6 到 8 周 | 满级后的持续目标 |

### 5.2 首批订单模板

- 谷仓补给：小麦、玉米。
- 早餐供应：面粉、鸡蛋、牛奶。
- 冬季工作服：棉花、羊毛、煤。
- 矿工补给：胡萝卜、鸡蛋、兔绒、铁矿。
- 温室骨架：棉花、肥料、铁锭。
- 庄园机械化：铜矿、铁锭、羊毛和金币。

订单奖励由服务端模板固定，包括：

- 金币；
- 庄园声望；
- 研究点；
- 限定但可追赶的收藏进度。

## 6. 世界事件与天气

事件必须提前展示影响，并提供至少两个有效选择。

首批事件：

### 持续干旱

- 农场照料需求增加；
- 牧场清洁成本上升；
- 矿山地下水下降，稀有矿脉发现率提高；
- 可选择建设水井、降低种植规模或扩大勘探。

### 丰收庆典

- 食品和纺织订单增加；
- 直接出售基础原料的价格降低；
- 加工设施速度提高；
- 完成庆典工程获得展示收藏。

### 山体渗水

- 矿井需要铁材和纺织防护；
- 农田短期自动获得水分；
- 可选择加固矿山、引水灌溉或暂停深层勘探。

### 寒潮

- 热带作物受影响；
- 牧场需要保温；
- 煤炭和纺织品需求上升。

世界事件的数值效果始终由规则引擎定义。LLM 只选择候选和生成故事。

## 7. LLM 世界导演

### 7.1 输入

只向 LLM 提供压缩后的结构化状态：

- 三个板块等级与主要短缺/过剩；
- 已建设设施；
- 最近订单和事件 ID；
- 当前世界事件候选；
- 玩家近期选择摘要；
- 可公开的 NPC 关系事实。

不发送完整存档、会话密钥、其他玩家私有库存。

### 7.2 输出

LLM 只能返回：

- 候选事件 ID；
- 标题；
- 简短叙事；
- NPC 台词；
- 对固定选项的解释；
- 不带执行权的经营建议。

输出必须经过结构校验；失败、超时或越界时使用确定性规则回退。

### 7.3 候选执行协议

```text
规则引擎构造合法候选
        ↓
LLM 返回 candidateId + narrative
        ↓
服务端确认 candidateId 存在
        ↓
执行候选中预定义的固定效果
        ↓
记录 eventId，不保存无限对话
```

沿用现有农场市场导演的候选选择模式，扩展为庄园导演，不允许 LLM 直接生成数值。

## 8. 时间节奏

| 系统 | 主要周期 |
|---|---|
| 农场 | 5 分钟到 18 小时 |
| 牧场 | 30 分钟到 12 小时 |
| 矿山 | 2 到 24 小时 |
| 加工设施 | 15 分钟到 8 小时 |
| 普通订单 | 当天 |
| 城镇工程 | 3 到 14 天 |
| 软赛季 | 6 到 8 周 |

一次典型登录控制在 3 到 8 分钟：

1. 收取三个板块的完成项；
2. 调整设施队列；
3. 提交订单；
4. 阅读天气和事件；
5. 安排下一轮生产。

## 9. 数据与架构

### 9.1 现有状态保持独立

- `farm_state`
- `ranch_state`
- `mine_state`

继续保存各板块权威状态，保证旧存档兼容和单板块规则清晰。

### 9.2 新增庄园状态

新增 `homestead_state`，承载：

- 庄园 revision；
- 声望与研究点；
- 加工品库存；
- 已建设设施和生产队列；
- 当前订单；
- 当前世界事件；
- LLM 叙事；
- 长期统计。

新增 `homestead_state_quarantine` 隔离无法恢复的庄园存档。

### 9.3 跨板块操作

新增共享领域模块 `shared/src/homestead.ts`：

- `createHomesteadGame`
- `refreshHomesteadGame`
- `applyHomesteadAction`
- `getHomesteadGameView`
- `assertRestorableHomesteadGameState`
- 配方、订单、事件模板

跨板块操作必须同时校验 farm、ranch、mine、homestead 四个 revision，并在单个数据库事务中保存。

### 9.4 API

新增：

- `GET /api/homestead`
- `POST /api/homestead/actions`

首批 action：

- 建设设施；
- 启动加工；
- 收取加工品；
- 完成联合订单；
- 刷新到期订单；
- 选择世界事件选项。

深度扩展 action：

- 解锁研究节点；
- 升级加工设施；
- 制定每日轮作计划并选择是否使用改良剂；
- 执行每日牧群饲料方案；
- 升级矿山防护并勘探指定矿层；
- 与三位庄园顾问按主题交流；
- 领取软赛季里程碑奖励。

上述 13 类庄园操作均由同一个权威 reducer 执行，统一校验四个
revision，并在 Web 庄园总览中提供可见入口。第一阶段存档缺少深度字段时
会自动补建默认状态，不隔离或重置原有存档。

### 完整改造落地状态

- 农场、牧场、矿山各有一次每日深度行动，并直接改变对应真实库存 revision。
- 土壤健康、牧群健康会按天衰减，轮作、营养和防护产生受上限约束的横向增益。
- 10 个研究节点包含前置条件、声望门槛和固定研究成本。
- 7 类设施均支持三级升级；升级影响加工时间和收取产量。
- 3 位 NPC 各有两个合法话题，最多保存 8 条结构化事实，不保存无限对话。
- LLM 只能选择合法事件并生成展示文本；执行数值仍全部来自规则模板。
- 软赛季持续 8 周，包含固定积分来源、3 档可追赶奖励和 45 项庄园图鉴。
- Web 对所有庄园服务端 action 设有静态可达性测试，防止后续出现 API 已存在但界面缺入口。

## 11. 第一阶段验收标准

第一阶段完成时必须满足：

1. 新用户可创建庄园状态，旧用户进入时自动补建，不修改原三业存档。
2. 至少存在 6 个加工设施、8 个跨板块配方和 4 个联合订单模板。
3. 至少一个配方同时消耗农场、牧场、矿山资源。
4. 加工启动、完成和收取具有权威时间校验。
5. 联合订单从真实三业库存与加工库存扣除资源。
6. 跨状态保存具备事务性，revision 冲突返回 409。
7. 存档校验失败时仅隔离庄园状态，不丢弃农场、牧场和矿山。
8. 共享规则、服务端路由、Web API 均有测试。
9. 类型检查、测试和生产构建通过。

完整阶段还必须满足：

10. 农、牧、矿三个深度动作可在同一天分别完成，且互不占用彼此的每日次数。
11. 研究、设施升级、防护升级、NPC 对话和赛季奖励均不能由客户端注入成本或收益。
12. 第一阶段庄园存档可自动迁移出研究、专精、NPC、赛季、图鉴和建议状态。
13. 每个深度 action 都能从 Web 界面到达，并具有禁用原因或资源条件提示。
14. LLM 叙事越界、缺失或调用失败时，规则建议和固定事件仍可独立运行。

## 12. 后续平衡指标

上线后至少记录：

- 不同配方的使用率；
- 三个板块的活跃占比；
- 原料直接出售与加工消耗比例；
- 订单完成率与放弃率；
- 设施队列空闲时长；
- 玩家卡住的原料类型；
- 世界事件选择分布；
- LLM 回退率、延迟和每活跃用户成本；
- 第 7、30、60、90 天仍存在的未完成长期目标数量。

预期结果：

- 基础内容寿命由 1 到 2 周提高到 30 到 60 天；
- 收藏、研究和软赛季提供 90 天以上目标；
- 三个板块的日活操作占比均不低于 20%；
- 不存在长期占优的单一短周期刷级策略。
