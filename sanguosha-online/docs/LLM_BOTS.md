# 大模型机器人架构

当前三国杀与斗地主均已接入可选大模型决策，够级继续使用原有同步规则机器人。三种游戏共用 `BotDecisionRegistry` 扩展边界，并由各自的私有视图适配器生成紧凑上下文。

## 安全边界

1. 规则引擎先生成合法候选动作。
2. 游戏适配器只投影机器人自己的手牌与公开信息，不传房间号、玩家 ID、昵称或其他玩家手牌。
3. 模型只能返回候选序号，不能自行构造动作。
4. 返回序号由注册表复验，最终动作仍交给权威规则引擎校验。
5. 超时、网络错误、无效 JSON 或越界序号时，立即使用本地规则策略。

API Key 仅由管理员提交给服务端，使用 AES-256-GCM 加密后存入数据库，不会进入房间快照、浏览器响应或日志。加密密钥由 `SESSION_SECRET` 派生，因此生产环境必须稳定保存该变量；更换它之前应先在管理后台清除 API Key。

## Token 控制

房间选择“大模型全程决策”后，三国杀机器人每次需要操作、斗地主机器人每次叫分、出牌或不出都会调用当前模型。Token 优化不通过跳过局面或限制每局调用次数实现，而集中在单次请求本身：

- 每次请求相互独立，不携带历史对话或上一轮提示词。
- 输入只包含机器人自己的牌、公开身份/手牌数量、当前牌型和合法候选序号；不发送日志、昵称或自然语言牌局复述。
- 牌点、身份和牌型使用短代码编码，所有等级使用相同的最多 10 个候选动作。
- 智力等级只改变一条精简系统策略提示词，不再改变调用次数或候选数量。
- 单次输出默认最多 16 Token，只允许 `{"i":序号}`。
- 调用数和 Token 用量仅用于显示和统计，会从房间快照恢复；下一局重新计数。

供应商未返回 `usage` 时，服务端按字符数保守估算 Token。

## 智力等级

| 等级 | 称号 | 分级提示词策略 | 调用方式 |
|---|---|---|---|
| 1 | 新手牌友 | 偏向首个简单低点数选项，尽量不用炸弹 | 每次行动调用 |
| 2 | 稳健农民 | 偏向低成本出牌，避免浪费强牌 | 每次行动调用 |
| 3 | 欢乐牌手 | 平衡出牌张数、牌点成本和叫分 | 每次行动调用 |
| 4 | 记牌能手 | 关注公开手牌数量，保留非决定性炸弹 | 每次行动调用 |
| 5 | 叫分专家 | 强化农民配合，安全时不压队友牌 | 每次行动调用 |
| 6 | 残局大师 | 优先拦截即将出完的对手并比较剩余牌型 | 每次行动调用 |
| 7 | 牌桌宗师 | 规划最短出完路径、协作、炸弹与立即威胁 | 每次行动调用 |

无论选择哪个等级，模型都看不到其他玩家未公开手牌。

真人轮到操作时，可在牌桌把“推荐方式”切换为“大模型推荐”并主动请求一次建议。服务端复用相同的私有视图和合法候选边界，只把建议返回给该玩家，不会自动执行；规则推荐仍可独立选择且零 Token。

## 管理后台配置

管理员登录后进入“管理”，可直接配置和热更新三国杀与斗地主大模型机器人，无需重启服务：

- 固定供应商：DeepSeek
- 模型可编辑：预置 `deepseek-v4-flash`（默认）和 `deepseek-v4-pro`，也可输入 DeepSeek `/models` 返回的其他模型 ID
- 固定接口：`https://api.deepseek.com/chat/completions`
- 默认关闭思考模式、单次输出 16 Token
- 保存 API Key 时页面留空代表保留原密钥，也可单独清除并同时停用大模型机器人
- “测试连接”使用 DeepSeek 的 `GET /models` 验证 API Key 和当前所选模型是否可用，不发起对局推理，也不产生模型输出 Token

供应商和接口地址在管理页面中为只读；模型可以选择或直接输入。三国杀与斗地主牌局中，只有机器人正在等待大模型返回时，才会在其座位显示“昵称 思考中...”；斗地主真人主动请求推荐时会显示“大模型正在推荐...”。

生产环境将配置保存在 PostgreSQL 的 `app_settings` 表；无数据库的本地测试模式保存在内存中，进程退出后清空。

环境变量仍可作为 DeepSeek 首次启动时的兼容引导配置。三个主要参数必须同时配置；数据库中已有管理后台配置时，以数据库为准。出于密钥安全考虑，非 `api.deepseek.com` 地址不会被后台配置服务接管：

```dotenv
DOUDIZHU_LLM_ENDPOINT=https://api.deepseek.com/chat/completions
DOUDIZHU_LLM_API_KEY=替换为服务端密钥
DOUDIZHU_LLM_MODEL=deepseek-v4-flash
DOUDIZHU_LLM_TIMEOUT_MS=4000
DOUDIZHU_LLM_MAX_OUTPUT_TOKENS=16
```

创建三国杀或斗地主房间时可选择“规则机器人”或“大模型全程决策”。如果房间选择了大模型、但服务端没有配置供应商，房间会明确显示“规则回退”，牌局仍可正常进行且不消耗 Token。
