# Splendor asset sources

The Splendor artwork in this directory is copied without regeneration from the
two upstream projects already credited by this repository.

## Classic Splendor

- Source: https://github.com/jrbarronumd/Splendor
- Source commit: `7c3bcf3f163b899794484366a61eed7456d7e37c`
- Local directory: `splendor-classic/`
- Copied upstream paths:
  - `public-files/images/cards/*.jpg`
  - `public-files/images/nobles/*.jpg`
  - `public-files/images/gems/*Gem.jpg`
  - `public-files/images/banner.jpg`

The card mapping follows the upstream deck names:

- Level 1: `green-NN.jpg`
- Level 2: `yellow-NN.jpg`
- Level 3: `blue-NN.jpg`
- Deck backs: the matching `*-00.jpg`
